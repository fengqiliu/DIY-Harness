# 验收验证

对照任务开始时的验收场景，从实际入口选择能够观察目标行为的检查。涉及接口、持久化或跨系统状态时，记录验证覆盖到哪一端，以及该端实际观察到的内容。

每项结果包含环境或版本、输入、命令或操作、预期、实际结果和状态。通过和失败均需实际观察；有意排除的检查记为「跳过」并说明原因，缺环境或缺证据的场景记为「未验证」。使用替身、合成数据或本地服务时写明覆盖边界。

失败时保留最短复现步骤与证据位置，交还给能修正该问题的角色。重试后记录新结果，并保留此前失败的上下文。给出交付结论时，说明哪些用户动作已有证据、哪些结论仍取决于现场或外部系统。
